# Triage-Labels

Die Skills sprechen von fünf kanonischen Triage-Rollen. Diese Datei bildet die Rollen auf die Label-Namen in diesem Repo ab.

| Rolle in mattpocock/skills | Label hier          | Bedeutung                                         |
| -------------------------- | ------------------- | ------------------------------------------------- |
| `needs-triage`             | `needs-triage`      | Maintainer muss das Issue bewerten                |
| `needs-info`               | `needs-info`        | Wartet auf weitere Angaben der meldenden Person   |
| `ready-for-agent`          | `ready-for-agent`   | Vollständig beschrieben, bereit für einen Agenten |
| `ready-for-human`          | `ready-for-human`   | Braucht eine Umsetzung durch einen Menschen       |
| `wontfix`                  | `wontfix`           | Wird nicht umgesetzt                              |

Nennt ein Skill eine Rolle (etwa „das Label für bereit für Agenten setzen“), gilt der Label-Name aus der rechten Spalte. Andere Namen trägt man dort ein.
