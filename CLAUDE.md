## Agent skills

### Issue tracker

Issues liegen als GitHub Issues in `h1f1x/fidelius`, bearbeitet mit der `gh` CLI. Siehe `docs/agents/issue-tracker.md`.

### Triage labels

Die fünf Standard-Rollen, jedes Label heißt wie seine Rolle (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). Siehe `docs/agents/triage-labels.md`.

### Domain docs

Single-context: eine `CONTEXT.md` und `docs/adr/` im Repo-Root. Siehe `docs/agents/domain.md`.
